# ☕ Café Brulhé 

Site web de commande de café réalisé dans le cadre d'un travail pratique en développement web.

## 📋 Présentation

Café Brulhé est une interface web permettant à un utilisateur de configurer une commande de café à travers plusieurs étapes.

Le projet met en pratique la création de pages web structurées en **HTML5**, la mise en forme avec **CSS3** et l'utilisation du framework **Bootstrap** pour créer une interface responsive.

## ✨ Fonctionnalités

* 🏠 Page d'accueil
* ☕ Sélection du type de breuvage
* 📏 Sélection du format
* 🌱 Choix du grain de café
* 🥛 Choix du nombre de laits
* 🍬 Choix du nombre de sucres
* ☕ Choix des doses d'espresso
* ✅ Page de confirmation de la commande
* 📱 Interface responsive grâce à Bootstrap

## 🛠️ Technologies utilisées

* HTML5
* CSS3
* Bootstrap 5.3.8

## 🚀 Utilisation

Aucune installation particulière n'est nécessaire.

Il suffit d'ouvrir le fichier `index.html` dans un navigateur web.

Le parcours de commande est accessible à partir de la page d'accueil :

**Accueil → Commande → Options → Confirmation**

## 🎯 Objectifs du projet

Ce travail permet de mettre en pratique :

* la structure d'une page HTML5;
* les formulaires HTML;
* les champs de sélection;
* les boutons radio;
* les contrôles de type `range`;
* la navigation entre plusieurs pages HTML;
* le responsive design;
* l'utilisation de Bootstrap;
* l'organisation d'un projet web.
